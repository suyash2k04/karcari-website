# Karcari Premium Frontend V5.5.4

## Key updates

- Hero has no product imagery and no scroll-progress counter.
- Hero portfolio figures animate from 0 → 10 Products and 0 → 6 Powders on load (about 1–2 seconds).
- The three strategy/info boxes use larger, more readable typography.
- Premix catalogue cards are restructured into a wider two-column premium grid on desktop.
- Product packs are substantially larger and use more of each card.
- Product titles, descriptions, facts, benefits, and enquiry actions are larger and clearer.
- Ingredient cards retain the premium B2B treatment with a readability increase.
- Premium footer from V5.3 is retained.
- Email and WhatsApp enquiry behavior is retained.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm run start
```
